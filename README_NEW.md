## 🚀 Getting Started

### Prerequisites
- Web Browser (Chrome, Firefox, Edge)
- Text Editor (VS Code recommended)
- XAMPP (for PHP projects)
- Node.js & npm (for React/Node projects)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/HEETMEHTA18/Web-Dev-Framework.git
   cd Web-Dev-Framework
   ```

2. **For HTML/CSS/JS projects**
   - Open `index.html` in your browser
   - Or use Live Server in VS Code

3. **For PHP projects**
   - Start XAMPP Apache server
   - Place project in `htdocs` folder
   - Access via `http://localhost/project-name`

4. **For Node.js/React projects**
   ```bash
   npm install
   npm start
   ```
